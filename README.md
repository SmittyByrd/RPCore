# RP Core
RP Core is a Minecraft plugin focused on providing several roleplay elements to the game. 

At this time, only one feature is implemented, with more to come.

## Planned Features
**Walking** - This feature will add a /walk command to the game, that when ran, will change player speed to almost half of standard. When executued again, player speed will return to normal.

** Character Cards** - This feature will implement a character card feature that will be customizable by each player.

**Chat Additions** - This feature will implement several roleplay inspired features to the standard multiplayer chat, such as whisper and shout.
